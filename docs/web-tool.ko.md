# 웹 팩 도구 (설치 없이 쓰는 테마 데이터 만들기)

`web/` 폴더는 브라우저에서 돌아가는 팩 도구입니다. 파이썬을 설치하거나 명령어를 칠 필요가 없습니다.
안에서는 `tools/`의 파이썬 코드를 그대로 돌리므로(Pyodide), 결과는 명령줄 도구와 똑같습니다.

> 영어판: [web-tool.en.md](web-tool.en.md) · 손으로 칠하는 방법: [hand-masks.ko.md](hand-masks.ko.md)

## 할 수 있는 것

1. **팩 넣기**: 팩 폴더나 zip을 끌어다 놓습니다. 버튼 시트만 읽습니다.
2. **설정**: 팩 종류(vanilla / glossy / whole 등)와 팩 이름을 고릅니다. 이미 만든 보정 파일이 있으면 함께 넣습니다.
3. **만들기**: `theme-data.zip`을 받아 팩 폴더 안에 풉니다(`GJ_GameSheet03-uhd.png` 옆에 `theme-data` 폴더).
   - **팩을 업데이트하면 theme-data도 다시 만드세요.** 버튼 배치가 바뀌었는데 옛 데이터가 남아 있으면, 모드가 이를 알아채고 그 시트에는 테마를 적용하지 않으며 게임 화면에 "theme data is out of date" 알림을 띄웁니다(엉뚱한 버튼에 색이 칠해지는 일은 없습니다).
4. **버튼 직접 칠하기**: 고칠 버튼을 골라 zip으로 꺼냅니다. 칠한 뒤 폴더나 zip을 다시 넣으면 고친 버튼만 등록되고, 3단계 "다시 만들기"로 반영됩니다.
   - 다음에 이어서 하려면 2단계의 "작업 저장"으로 보정 파일과 칠한 마스크를 zip으로 받아 두세요.

팩 파일은 서버로 올라가지 않고 그 브라우저 안에서만 처리됩니다.
에어로 팩 기준으로 whole은 약 15초, glossy는 약 45초 걸립니다(첫 실행은 엔진을 받느라 조금 더 걸립니다).

## 사이트로 올리기 (GitHub Pages, 무료)

서버를 돌릴 필요가 없는 정적 사이트입니다. 파일을 올려 두기만 하면 계속 동작합니다.

1. 이 프로젝트(`GD-Diamond-Theme` 폴더 전체)를 GitHub 저장소에 올립니다.
   - 웹 도구는 `../tools/`의 파이썬 파일을 불러오므로 `web/`과 `tools/`가 함께 있어야 합니다.
2. 저장소의 **Settings → Pages**에서 Source를 "Deploy from a branch", 브랜치는 `main`, 폴더는 `/ (root)`로 둡니다.
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소>/web/` 에서 열립니다.

- 루트의 `.nojekyll` 파일은 GitHub가 파일을 손대지 않고 그대로 내보내게 합니다. 지우지 마세요.
- `preview/assets`처럼 남의 팩에서 나온 로컬 분석 자료는 올리기 전에 빼세요(`"local": true`로 표시된 팩).
- 파이썬 엔진(Pyodide)은 jsDelivr CDN에서 받으므로 쓰는 사람에게 인터넷 연결이 필요합니다.

## 내 컴퓨터에서 시험하기

```bash
python -m http.server 8766 --directory GD-Diamond-Theme
```

브라우저에서 `http://localhost:8766/web/` 을 엽니다. (`file://`로 직접 열면 작업자가 동작하지 않습니다.)

## 구조

| 파일 | 역할 |
|---|---|
| `web/index.html` | 화면 |
| `web/app.js` | 파일 고르기/끌어다 놓기, 버튼, 내려받기 (한국어/영어) |
| `web/worker.js` | 화면과 따로 파이썬을 돌리는 작업자. Pyodide를 받고 `tools/*.py`를 불러온다 |
| `web/webtool.py` | 웹용 연결부: 가상 폴더(`/pack`, `/project`, `/hand`, `/out`)와 zip 처리, 칠한 마스크 가져오기 |

- 웹에서 꺼낸 작업 폴더의 `hand-masks.json`에는 버튼마다 꺼낸 마스크의 지문(`maskSha1`)이 들어갑니다. 가져올 때 이걸로 "고친 버튼"을 알아보므로, zip으로 다시 묶어도 파일 시각과 상관없이 정확합니다.
- 명령줄 `hand_masks.py`로 꺼낸 폴더도 웹에서 가져올 수 있습니다(이때는 파일 시각으로 판단합니다).
