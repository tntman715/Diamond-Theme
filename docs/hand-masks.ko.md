# 버튼 수기 분리 가이드

광택·렌더링 스타일처럼 자동으로 잘 나뉘지 않는 팩은, 버튼의 테두리/바탕/아이콘을 그림 프로그램에서 직접 칠해서 지정할 수 있습니다.
자동 분리 결과에서 시작하므로 처음부터 그리는 것보다 빠릅니다.

> 영어판: [hand-masks.en.md](hand-masks.en.md) · 자동 분리와 영역 번호 보정: [tuning-guide.ko.md](tuning-guide.ko.md)
>
> **파이썬 없이 하려면** [웹 팩 도구](web-tool.ko.md)의 4단계를 쓰세요. 꺼내기/가져오기/다시 만들기가 브라우저에서 됩니다. 칠하는 방법(아래 2단계)은 같습니다.

## 언제 쓰나

| 방법 | 언제 |
|---|---|
| 자동 분리 그대로 | 잘 나뉜 버튼 |
| 영역 번호 보정 (`"regions"`) | 조각은 맞게 나뉘었는데 이름표(테두리/바탕/아이콘)만 틀린 버튼 |
| **수기 분리 (이 문서)** | 조각 자체가 잘못 나뉜 버튼 (글자가 판과 붙음, 광택과 그림이 붙음 등) |
| 분할 없음 (`"whole": true`) | 부위별 색 바꾸기 없이 전체 효과만 원하는 버튼 |

vanilla/glossy 팩에서는 섞어 쓸 수 있습니다. 대부분은 자동으로 두고, 눈에 띄는 버튼 몇 개만 손으로 칠하면 됩니다.

단, **분할 없음(whole) 프로필로 만든 팩은 모든 버튼이 한 덩어리**입니다. 손으로 칠한 마스크와 영역 보정은 무시됩니다. 일부 버튼만 바탕/아이콘 색이 바뀌면 같은 설정에 버튼마다 다르게 반응하기 때문입니다. 칠한 버튼을 쓰려면 팩을 vanilla/glossy로 만드세요(`--whole-fallback`을 붙이면 나머지는 한 덩어리로 남습니다).

## 준비

- Python 3.10 이상, `pip install numpy pillow scipy`
- 그림 프로그램: Krita 또는 GIMP(무료, `.ora` 레이어 파일을 바로 엶)를 권장합니다. 포토샵이나 다른 프로그램도 PNG로 작업할 수 있습니다.
- 명령은 `GD-Diamond-Theme` 폴더에서 실행합니다.

## 1단계: 꺼내기

```
python tools/hand_masks.py export "팩 폴더" 작업폴더 --profile glossy --frames GJ_achBtn_001.png GJ_freeStuffBtn_001.png --base-plists "GD Resources"
```

- `--frames` 대신 `--match "Btn"` 같은 정규식으로 여러 개를 한 번에 꺼낼 수 있습니다.
- 이미 쓰는 보정 파일이 있으면 `--overrides 보정파일.json`을 붙이세요. 보정이 반영된 상태에서 시작합니다.
- `--profile`은 팩에 맞게 고릅니다: 검은 선이 있는 팩 `vanilla`, 광택 팩 `glossy`, 분할 없음 `whole`.

작업 폴더에 버튼마다 폴더가 생깁니다.

| 파일 | 내용 |
|---|---|
| `original.png` | 원본 버튼 (참고용, 고치지 않음) |
| `mask.png` | 지금 자동 분리 결과. **이걸 고칩니다** |
| `<버튼>.ora` | 원본과 마스크를 레이어로 묶은 파일. Krita/GIMP에서 "mask" 레이어를 고칩니다 |
| `guide.png` | 원본 위에 마스크를 겹친 참고 그림 |

버튼은 바로 세운 방향으로 나옵니다(시트 안에서 돌아가 있는 버튼도).

## 2단계: 칠하기

| 색 | 뜻 |
|---|---|
| 빨강 `#FF0000` | 테두리: 버튼 가장자리를 두른 링 |
| 초록 `#00FF00` | 바탕: 버튼의 판(배경). 광택·반사도 판에 속하면 바탕 |
| 파랑 `#0000FF` | 아이콘: 판 위에 그린 그림·글자 |
| 검정 또는 지우개 | 원본 그대로 (색을 바꾸지 않음): 그림자, 꼭 원래 색이어야 하는 장식 |

- **가장자리**: 부드럽게 칠해도 됩니다. 섞인 색은 비율대로 나뉩니다(예: 빨강 50% + 초록 50%).
- **바꾸면 안 되는 것**: 그림 크기, 방향, 위치. 바뀌면 가져오기에서 오류로 알려 줍니다.
- **버튼 바깥(투명한 곳)**: 어떻게 칠해도 상관없습니다.
- **판단 기준**: "이게 버튼의 판인가, 판 위에 그린 것인가?"로 정하면 됩니다. 판 전체를 덮는 광택은 바탕, 그림 위에만 있는 하이라이트는 아이콘입니다.
- **프로그램별 저장 방법**:
  - Krita/GIMP: `.ora`를 열고 "mask" 레이어를 칠한 뒤 `.ora`로 저장합니다.
  - 포토샵 등: `original.png` 위에 `mask.png`를 레이어로 올려 반투명하게 보면서 칠하고, `mask.png`로 저장합니다.

## 3단계: 가져오기

```
python tools/hand_masks.py import 작업폴더 보정파일.json
```

- 고친 버튼만 가져옵니다(`.ora`와 `mask.png` 중 나중에 저장한 쪽). 안 고친 버튼은 건너뜁니다.
- 칠한 마스크는 `<보정파일 이름>-masks/` 폴더에 복사되고, 보정 파일에 `"mask": "..."`로 등록됩니다.
- 버튼마다 `작업폴더/<버튼>/check.png`로 확인할 수 있습니다: 원본 | 칠한 마스크 | 결과 미리보기.

## 4단계: 테마 데이터 다시 만들기

```
python tools/make_theme_data.py "팩 폴더" "팩 폴더" --profile glossy --base-plists "GD Resources" --overrides 보정파일.json
```

칠한 버튼은 자동 분리 대신 칠한 마스크를 씁니다. 게임이 켜져 있으면 보통 1초 안에 다시 읽습니다.

## 다시 고치기

- 다시 `export`(같은 `--overrides`)를 하면 칠해 둔 마스크가 들어간 상태로 다시 꺼내집니다.
- 수기 마스크를 지우고 자동 분리로 돌아가려면 보정 파일에서 그 버튼의 `"mask"` 줄을 지우세요.
