# Diamond Theme

Customizable, animated UI themes for Geometry Dash (Geode mod `tntman.diamond-theme`):
recolor buttons by outline / body / icon, hue animation, glass and frosted glass, emboss, jelly press animation.
Works with Diamond Pack, Diamond Vortex, vanilla GD, and any texture pack that ships theme data.

지오메트리 대시 UI 테마 모드: 버튼의 테두리/바탕/아이콘 색 바꾸기, 색조 애니메이션, 유리·젖빛 유리, 엠보싱,
쫀득한 누름 애니메이션. Diamond Pack, Diamond Vortex, 바닐라 GD, 테마 데이터가 들어 있는 텍스쳐 팩에서 동작합니다.

## Download / 받기

Get `tntman.diamond-theme.geode` from the latest release and put it in Geometry Dash's `geode/mods` folder.
최신 릴리스에서 `tntman.diamond-theme.geode`를 받아 게임의 `geode/mods` 폴더에 넣으세요.

## Repository layout / 구성

| Path | Contents |
|---|---|
| `mod/` | The Geode mod (C++) / 게임 안에서 도는 모드 |
| `tools/` | Python tools that build theme data from a texture pack / 텍스쳐 팩에서 테마 데이터를 만드는 도구 |
| `web/` | Browser version of the pack tool / 설치 없이 쓰는 웹 팩 도구 |
| `docs/` | Guides (Korean / English) / 안내 문서 |
| `preview/` | Theme preview page / 테마 미리보기 |
